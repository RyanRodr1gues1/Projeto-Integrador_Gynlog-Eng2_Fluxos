
# 📌 Projeto Integrador 1 (PI)

Este repositório contém o **Projeto Integrador I**, desenvolvido como parte do curso de **Engenharia de Software**, com o objetivo de aplicar na prática os conceitos aprendidos ao longo do curso.

No meu primeiro Projeto Integrador (PI), para compor a nota do segundo período do curso de Eng. de Software na Faculdade SENAI Fatesg junto ao meus colegas, desenvolvi um sistema em Java utilizando a arquitetura MVC.

---

## 🎯 Objetivo do Projeto

O Projeto Integrador tem como finalidade:
- Integrar conhecimentos teóricos e práticos
- Desenvolver soluções utilizando **lógica de programação**
- Aplicar conceitos de **engenharia de software**
- Trabalhar com **boas práticas de desenvolvimento**

---

## 🧠 Conceitos Aplicados

- Lógica de Programação  
- Programação Orientada a Objetos  
- Estrutura de Dados  
- Engenharia de Requisitos  
- Arquitetura de Software  
- Desenvolvimento de Sistemas
